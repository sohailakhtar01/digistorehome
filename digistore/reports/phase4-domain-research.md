## Before buying anything

1. **Trademark check.** RDAP says nothing about trademarks. Any name near a live brand
   needs a USPTO TESS search first.
2. **History check.** An available name may have been registered and dropped before,
   possibly carrying spam history. Check the Wayback Machine before committing.
3. **The Bing gap is still open.** No Bing SERP has been validated for any of these
   clusters — see `data/serp/phase35-bing-fault.md`. Buying a domain does not depend on
   it, but choosing which cluster to build does.
